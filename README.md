# תכ״ם ברור — אב־טיפוס לחיפוש בהוראות רכש

POC בעברית וב־RTL המדגים איתור הוראות בפרק 7, "התקשרויות ורכישות", באתר
תכ״ם. המשתמש שואל שאלה בשפה חופשית, השרת מחפש במטא־נתונים ובמילות המפתח
שהקטלוג הרשמי מציג, ומחזיר רשומות מדורגות עם קישורים ישירים למקור.

## הבעיה והפתרון

בבדיקת אתר תכ״ם נמצאו מאות הוראות המאורגנות בפרקים ובתתי־פרקים. פרק
ההתקשרויות והרכישות כולל נושאים שונים, כגון ועדות מכרזים, הליך מכרזי, פטור
ממכרז ופרסום. מציאת ההוראה הרלוונטית דורשת להכיר את מונחי האתר ולנווט
בקטלוג.

הפתרון המוצע הוא ממשק חיפוש בשפה טבעית שמקשר את ניסוח המשתמש למונחי הקטלוג,
מציג את פרטי ההוראה ומאפשר לפתוח את המקור הרשמי. במקרה שאין התאמה, הוא אומר
זאת במפורש ולא מייצר תשובה.

## מה עובד ב־POC

- ממשק React רספונסיבי בעברית ובכיווניות RTL.
- API ב־Node.js ו־Express עם `POST /api/ask`, `GET /api/health`, ולידציה
  והגבלת שאלה ל־500 תווים.
- חיפוש מדורג במספר ההוראה, בכותרת, בתחום ובמילות המפתח הרשמיות, כולל התאמה
  בסיסית לתחיליות נפוצות בעברית.
- שש רשומות ממוקדות בפרק 7, עם גרסה ותאריך תחולה וקישור ישיר לאתר תכ״ם.
- תשובת הדגמה דטרמיניסטית. היא מציגה רק פרטי קטלוג ואינה טוענת שמילות המפתח
  הן ציטוט או כלל מחייב מההוראה.
- שילוב אופציונלי של מודל שפה בצד השרת בלבד. הוא כבוי כברירת מחדל, וכאשר
  מופעל מקבל רק את רשומות הקטלוג שאותרו — לא את נוסח ההוראות.
- בדיקות אוטומטיות למספר הוראה, חיפוש מילות מפתח, דירוג מקורות והתנהגות
  כשאין התאמה.

## מדגם הנתונים

המידע נאסף ידנית מן הקטלוג ומנקודות המידע הציבוריות באתר תכ״ם ונבדק
ב־25.10.2026. נאספו שש הוראות; לא הורד או נשמר כאן תוכן מלא של מסמכים.
המאגר כולל כותרת, פרק ותת־פרק, מילות מפתח, מהדורה, תאריך תחולה וקישור רשמי.
מילות המפתח משמשות לאחזור בלבד.

| הוראה | כותרת | נושא |
|---|---|---|
| 7.0.1 | הגדרות בנושא התקשרויות ורכישות | הגדרות |
| 7.1.1 | ועדות מכרזים וועדות פטור בממשלה | ועדות מכרזים ועבודתן |
| 7.4.1 | ניהול ההליך המכרזי | ניהול מכרז |
| 7.6.1 | פטור מחובת המכרז | התקשרות בפטור ממכרז |
| 7.7.1 | התקשרות בהליך מקוצר | התקשרות בהליך תחרותי |
| 7.9.1 | פרסום מכרזים והתקשרויות | חובת פרסום פומבי |

הקטלוג ומסמכי המקור הרשמיים נמצאים ב־[אתר תכ״ם](https://takam.mof.gov.il/).
כתובות המקור המדויקות נשמרות יחד עם הנתונים ב־`server/knowledge.js`.
לפני שימוש מקצועי יש לפתוח את ההוראה באתר ולוודא שהמהדורה והתוקף לא השתנו.

## הפעלה

נדרשת Node.js בגרסה 20 ומעלה. ב־PowerShell של Windows אפשר להשתמש ב־`npm.cmd`
אם מדיניות ההרצה חוסמת את `npm.ps1`:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run dev
```

פתחו `http://localhost:3000`. אין צורך במפתח API להפעלת הדמו.

בנייה והרצה במצב Production מקומי:

```powershell
npm.cmd run build
$env:NODE_ENV = "production"
npm.cmd start
```

## תרחישי בדיקה והדגמה

1. `מה ידוע על הוראה 7.6.1 בנושא פטור ממכרז?` — התאמה לפי מספר ונושא, פרטי
   קטלוג וקישור למקור הרשמי.
2. `אילו מילות מפתח מקושרות להליך מקוצר?` — התאמה לפי מילות המפתח של הוראה
   7.7.1.
3. `איפה נמצא מידע על ועדת מכרזים?` — איתור הוראה 7.1.1 לפי מילות מפתח.
4. `איך מגישים בקשה לאישור חופשה?` — תשובת "לא נמצאה התאמה", ללא המצאת נוהל.
5. שאלה ריקה או ארוכה מ־500 תווים — ה־API מחזיר שגיאת קלט.

## ארכיטקטורה והחלטות

```text
דפדפן (React, RTL)
  └── POST /api/ask
        ├── אימות קלט (Express)
        ├── אחזור לקסיקלי מדורג (server/search.js)
        ├── תשובת הדגמה המבוססת על מטא־נתונים (server/question.js)
        └── מודל שפה אופציונלי (כבוי כברירת מחדל, בצד השרת בלבד)
```

- React מספק ממשק אינטראקטיבי עם מצבי טעינה, תוצאות ושגיאות מפורשות.
- Node.js ו־Express מספקים API קטן, ולידציה ומיקום צד־שרת למפתח המודל.
- החיפוש הלקסיקלי קל לבדיקה ופועל ללא שירות חיצוני; הוא מתאים להדגמת POC
  במאגר קטן, אך אינו מנוע סמנטי ואינו מבין את תוכן ההוראות.
- לא הופעל מודל חיצוני כברירת מחדל. זו בחירה שמונעת שליחת שאלות לספק חיצוני
  ללא הגדרה מפורשת, ומתאימה יותר להדגמה בסביבה ממשלתית.

### הפעלה אופציונלית של מודל שפה

העתיקו את `.env.example` ל־`.env`, הגדירו `ENABLE_OPENAI=true` ואת
`OPENAI_API_KEY`, וטענו את המשתנים בסביבת ההרצה. השרת אינו טוען קובצי `.env`
אוטומטית. המודל מקבל את השאלה ואת תוצאות הקטלוג בלבד; הוא אינו יכול לבסס
תשובות על נוסח מסמך שאינו במאגר. אין להכניס מפתח לקוד, לדפדפן או לחבילת
ההגשה, ואין לשלוח מידע רגיש לספק חיצוני ללא אישור.

## מגבלות ומה נדרש להמשך

- המדגם כולל שש רשומות בלבד. הוא אינו מייצג את כל הוראות תכ״ם.
- אין במאגר את גוף ההוראות, ולכן המערכת אינה יכולה להשיב על תנאי זכאות,
  תהליכים מחייבים, חריגים או פרשנות משפטית. מילות מפתח הן תוויות קטלוג ולא
  מקור לניסוח כללים.
- תאריך התחולה והמהדורה משקפים את הקטלוג בזמן איסוף המדגם, לא סנכרון חי.
- החיפוש הוא לקסיקלי; ניסוחים נרדפים שלא מופיעים בקטלוג עלולים לא להימצא.
- אין להשתמש בדמו לקבלת החלטה מקצועית או משפטית. יש לבדוק את נוסח ההוראה
  הרשמי ואת העדכניות שלו.

להרחבה ל־Production נדרשים: אישור ותהליך סנכרון של מסמכי המקור, גרסאות
ומועד עדכון; אינדוקס של הטקסט המלא עם ציטוטים מדויקים; חיפוש היברידי עם
סינון תוקף; הערכת Recall@k ודיוק ציטוטים על שאלות אמת; ניטור, הרשאות,
Rate limiting ומדיניות שמירת נתונים. בסביבה מנותקת מאינטרנט יש לארח את
המודל ואת האינדקס בתוך הרשת המאושרת, או להשאיר את המערכת במצב חיפוש ללא
מודל חיצוני.
